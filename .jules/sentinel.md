## 2024-05-24 - [IDOR in Post Creation and Missing Route Authentication]
**Vulnerability:** The `POST /api/posts` and `POST /api/posts/:id/react` endpoints lacked authentication middleware in the routes definition. Furthermore, the `createPost` controller implicitly trusted `req.body.userId`, allowing any user to potentially create posts masquerading as someone else (IDOR).
**Learning:** Controller logic alone is insufficient if the middleware protecting it is missing from the route. User-supplied identification data (like `userId` in the body) should never be trusted for actions linked to the authenticated user.
**Prevention:** Always verify that routes defining state-changing endpoints (POST, PUT, DELETE) have authentication middleware applied. Within controllers, always rely on `req.user.id` (set by the authentication middleware) to determine the user performing the action, rather than relying on the client to send a `userId`.

## 2024-06-18 - [PII Leakage in API Controllers]
**Vulnerability:** Several controllers (`post.controller.js`, `user.controller.js`) were exposing sensitive user information (specifically email addresses) by including the `email` attribute in their default payload for resource fetching and user searching, even to unauthenticated users or those without an explicit "accepted" friendship status.
**Learning:** Returning default or overly broad arrays of attributes across all REST responses without considering the user's role and authorization level exposes sensitive PII. In applications like social platforms, public resources (posts, profile searches) should only ever include non-sensitive profile information (`id`, `displayName`, `avatarUrl`) to prevent scraping or unintended disclosure.
**Prevention:** Always explicitly define the attributes strictly necessary for a given API response. Ensure `email` and other sensitive columns are excluded from any standard queries accessible to the general public or broad user base unless specifically required and authorized (e.g., retrieving one's own profile).
